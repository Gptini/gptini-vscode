# GPTini

VS Code에서 GPTini 채팅을 사용할 수 있는 익스텐션입니다.

## 설치 방법

1. `.vsix` 파일 다운로드
2. VS Code에서 `Ctrl+Shift+P` → `Extensions: Install from VSIX...` 선택
3. 다운로드한 `.vsix` 파일 선택

## 사용 방법

1. 좌측 액티비티 바에서 채팅 아이콘 클릭
2. 메시지 입력 후 전송

## 설정

| 설정 | 설명 | 기본값 |
|------|------|--------|
| `gptini.serverUrl` | 백엔드 서버 URL | - |
